# Measuring 55/45 Centering on Full-Frame Cards: Border Parameter Matrix and Worked Example

Published 2026-11-14

![Cover](<https://www.yaykey.com/_astro/cover-geometry-1.B4Xm_Z3z.webp>)

Measure 55/45 centering on full-frame cards with a reproducible geometric method: define total left-right border width S, one-side offset and left-right width difference, with an S=6mm worked example and notes on perspective and recheck error. **55/45 describes the ratio of the left border width to the right border width; the basis for judgment is measured width, not first impression.
